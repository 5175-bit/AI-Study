# 多运动场景下的二维轨迹预测：CV、MLP、GRU 与残差 GRU 对比

使用 PyTorch 在**合成二维运动轨迹**上比较物理预测基线与神经网络方法。项目覆盖匀速直线、匀变速直线和恒速转弯三种场景，重点考察多步预测误差、不同运动模式的泛化表现，以及物理先验与数据驱动模型结合的效果。

> **实验结论：**在当前合成数据与实验设置下，简单的恒速模型（CV）在独立测试集上取得了最好的整体 ADE 和 FDE。引入 GRU 或残差修正并不必然提高预测精度。这是项目的真实结果，也是值得分析的部分。

## 1. 任务与数据

- **任务：**根据连续 10 个历史二维坐标，预测之后 30 个时刻的位置。
- **采样间隔：**0.1 s；预测覆盖之后约 3 s。
- **数据来源：**Python 生成的合成运动轨迹，**不涉及真实道路数据集**。
- **运动场景：**匀速直线、匀变速直线、恒速转弯；每类生成 20 条轨迹，每条 100 个位置点。
- **划分方式：**按完整轨迹划分训练、验证、测试集，避免同一条轨迹的高度重叠滑动窗口同时进入不同集合。每类分别划分为 14 / 3 / 3 条轨迹。
- **样本数量：**训练集 2562、验证集 549、测试集 549；滑动窗口输入为 `(10, 2)`，目标为 `(30, 2)`。

三种运动场景具有不同的预测难点：

1. **匀速直线：**短期速度和方向不变，CV 的假设与数据生成机制一致。
2. **匀变速直线：**速度随时间变化，恒速外推会产生系统性偏差。
3. **恒速转弯：**速率基本不变，但速度方向持续改变，沿切线外推的 CV 无法准确跟踪曲线。

## 2. 对比方法

| 方法 | 思路 | 在本实验中的作用 |
| --- | --- | --- |
| CV（Constant Velocity） | 依据最后两个观测位置估计位移增量，按恒速外推 | 不需要训练的物理基线 |
| Relative MLP | 将历史位置转换为相对坐标，经多层感知机一次输出全部未来位置 | 检查前馈网络能否学习运动规律 |
| Relative GRU | 用门控循环单元处理历史序列，再一次输出 30 个二维位置 | 检查序列建模是否带来优势 |
| CV + GRU | 用 CV 生成预测，再由 GRU 学习修正量 | 检查物理先验与残差学习的效果 |

CV 的计算公式为

\[
\hat{\boldsymbol p}_{t+k}=\boldsymbol p_t+k(\boldsymbol p_t-\boldsymbol p_{t-1}),\qquad k=1,\ldots,30.
\]

这里每个位置向量包含 x、y 两个坐标，采样间隔保持固定。

残差模型使用

\[
\hat{\boldsymbol P}_{\mathrm{CV+GRU}}=
\hat{\boldsymbol P}_{\mathrm{CV}}+f_{\mathrm{GRU}}(\boldsymbol X_{\mathrm{rel}}),
\]

其中相对位置由历史位置减去最后一个观测位置得到。该设计让 GRU 主要尝试学习 CV 尚未解释的部分。

## 3. 训练与评价

- **优化方法：**Adam；学习率 `0.001`。
- **训练上限：**120 个 Epoch。
- **早停机制：**验证损失连续 20 个 Epoch 未改善则停止，保存验证损失最小时的模型。
- **随机种子：**实验中使用 `torch.manual_seed(42)`，以减小部分随机因素的影响。
- **损失函数：**均方误差 MSE。
- **评价指标：**ADE（所有未来预测时刻的平均欧氏距离误差）和 FDE（最后一个预测时刻的欧氏距离误差），数值越低越好。

模型的多步预测是通过线性预测头**一次性输出**未来 30 个位置，并非自回归地逐时刻生成。

## 4. 结果

### 整体测试集结果

以下数值来自**最终独立测试集**，不是训练损失。

| 方法 | ADE ↓ | FDE ↓ |
| --- | ---: | ---: |
| **CV** | **0.147257** | **0.413176** |
| MLP | 0.252208 | 0.639464 |
| GRU | 0.285029 | 0.669850 |
| CV + GRU | 0.156168 | 0.421769 |

### 测试集分场景结果

| 运动场景 | 模型 | ADE ↓ | FDE ↓ |
| --- | --- | ---: | ---: |
| 匀速直线 | CV | **0.000008** | **0.000015** |
| 匀速直线 | MLP | 0.083394 | 0.188240 |
| 匀速直线 | GRU | 0.157828 | 0.326537 |
| 匀速直线 | CV + GRU | 0.017828 | 0.024567 |
| 匀变速直线 | CV | **0.036034** | **0.101344** |
| 匀变速直线 | MLP | 0.185027 | 0.449068 |
| 匀变速直线 | GRU | 0.171059 | 0.410617 |
| 匀变速直线 | CV + GRU | 0.048651 | 0.111362 |
| 恒速转弯 | CV | 0.405728 | 1.138168 |
| 恒速转弯 | MLP | 0.488202 | 1.281085 |
| 恒速转弯 | GRU | 0.526201 | 1.272396 |
| 恒速转弯 | CV + GRU | **0.402024** | **1.129378** |

### 主要观察

1. **CV 是强基线。**匀速直线场景几乎没有预测误差；简单、正确的物理假设在这组数据上胜过更复杂的神经网络。
2. **转弯更难预测。**即使速率固定，方向变化也会让 CV 的位置误差随预测时间增大。
3. **残差修正仅带来局部改善。**CV + GRU 在测试集转弯场景略微优于 CV，但在测试集整体、匀速直线和匀变速直线上均未超过 CV，不能据此声称残差方法普遍有效。
4. **验证与测试要分开。**残差 GRU 的最优验证 Epoch 为 1，验证 MSE 约为 `0.028826`；相同划分下 CV 的验证 MSE 约为 `0.028808`，说明学习修正量的收益非常有限。

python path_comparison.py

## 6. 局限性与下一步

- 数据由简化的运动方程生成，与真实驾驶环境中的噪声、驾驶行为、交互关系和道路约束存在显著差异。
- 每类只有 20 条独立轨迹，其中测试集每类 3 条，滑动窗口数量虽然较多，但**不等同于拥有几百条独立轨迹**。
- 当前未展示多次随机种子实验和置信区间，因此不宜过度解读小幅指标差异。
- 模型是单轨迹、单目标预测，没有考虑周围车辆和地图信息。

下一步可以在保持独立轨迹划分的前提下，增加速度、加速度、转向角速度等运动学特征；尝试恒加速度（CA）与恒转率（CTRV）基线；然后迁移到公开的真实驾驶轨迹数据集。每次都应继续报告 CV 等简单基线。
